        What to know before relying on it

        Where the data comes from

        Every record is a report published by BMKG (Badan Meteorologi, Klimatologi, dan Geofisika). Heiz stores it and does not measure or recalculate anything.

        Not for safety decisions

        Heiz does not predict earthquakes and is not a warning system. For official information use bmkg.go.id.

        Data is not instant

        New events appear only after a sync from BMKG runs, so the map can lag behind BMKG. The status line shows when the last sync happened.

        The database can be down

        It runs on a free hosting tier. When it is unreachable the API answers 503 with a retry hint, and this page shows the last data saved on your device.
