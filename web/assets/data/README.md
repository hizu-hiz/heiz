# outline.json

Country outlines for the offline map fallback (Indonesia and neighbours), rounded to 0.01 degree.

- Data: Natural Earth (https://www.naturalearthdata.com), 1:50m Admin 0 Countries. Public domain.
- Obtained through the `world-atlas` npm package v2.0.2 (https://github.com/topojson/world-atlas, ISC licence), converted with `topojson-client` 3.1.0.
- Boundaries on Natural Earth maps are not an authority on disputed borders; this file is for orientation only.
